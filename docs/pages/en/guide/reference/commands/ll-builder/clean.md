## NAME

ll-builder-clean - Clean build artifacts

## SYNOPSIS

**ll-builder clean** [*options*]

## DESCRIPTION

The `ll-builder clean` command is used to remove the build artifacts generated by a previous build. These artifacts are stored in the `linglong/` directory of the current working directory.

If the `linglong/` directory does not exist, the command succeeds without doing anything.

## OPTIONS

**-h, --help**
: Print help information and exit

**--help-all**
: Expand all help

**-f, --file** _FILE_
: Specify a project configuration file under the current working directory. If omitted, `linglong.<current-architecture>.yaml` is preferred when it exists; otherwise, `linglong.yaml` is used

## EXAMPLES

Clean the build artifacts of the project in the current working directory:

```bash
ll-builder clean
```

Specify a project configuration file explicitly:

```bash
ll-builder clean --file linglong.custom.yaml
```
