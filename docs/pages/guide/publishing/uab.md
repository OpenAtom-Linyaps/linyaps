# UAB 应用发布

本文档补充使用 UAB（Universal Application Bundle）进行应用发布的相关内容。

## 什么是 UAB

UAB（Universal Application Bundle，通用应用包）是一种跨发行版的应用程序打包格式，旨在解决 Linux 应用在不同发行版之间的兼容性问题。它将应用程序及其所需依赖打包成单个文件，实现一键安装与运行。

## UAB 发布的优势

- **跨发行版兼容**：采用 UAB 格式打包的应用可在不同的 Linux 发行版上无缝运行
- **一键式安装**：用户仅需下载单个包文件即可完成安装
- **依赖自包含**：软件包内包含所需依赖，避免系统依赖冲突
- **分发便捷**：单文件易于网络传输与离线分享

## 创建 UAB 软件包

### 前提条件

在创建 UAB 软件包之前，你需要：

1. 完成应用程序的开发与测试
2. 确保应用在如意玲珑环境中可正常运行
3. 准备好应用的元数据信息（名称、版本、描述等）

### 构建流程

1. 使用 `ll-builder` 构建应用：

```bash
ll-builder build
```

2. 导出为 UAB 格式：

```bash
ll-builder export --type=uab
```

3. 生成的 UAB 文件将保存在当前目录下，文件名格式为：`{app-id}_{version}_{arch}.uab`

## UAB 文件结构

UAB 文件本质上是一个自包含的压缩包，包含：

- 应用可执行文件与资源文件
- 所需依赖库与运行环境
- 应用元数据与配置文件
- 安装脚本与桌面图标（desktop）文件

## 发布 UAB 应用

### 方式一：直接分发

你可以通过以下方式直接将生成的 UAB 文件分发给用户：

- 官方网站下载
- GitHub Releases
- 第三方软件下载站点
- U盘等离线存储介质

### 方式二：仓库发布

将 UAB 文件上传至如意玲珑仓库：

```bash
ll-builder push --repo=your-repo
```

### 方式三：应用商店发布

通过官方渠道将应用提交至应用商店，应用商店将自动处理 UAB 软件包并提供给用户下载。

## 用户安装

用户可以通过以下方式安装 UAB 应用：

### 命令行安装

```bash
ll-cli install ./your-app.uab
```

### 图形界面安装

双击 UAB 文件，系统将自动调用如意玲珑安装器完成安装。

## UAB 应用管理

### 查看已安装应用

```bash
ll-cli list
```

### 更新应用

```bash
ll-cli update your-app-id
```

### 卸载应用

```bash
ll-cli uninstall your-app-id
```

## 最佳实践

1. **版本管理**：采用语义化版本（Semantic Versioning）规范管理应用版本号
2. **多环境测试**：在多种 Linux 发行版上进行测试，确保兼容性
3. **完备文档**：提供清晰详尽的安装与使用说明
4. **定期更新**：及时跟进上游应用与依赖更新
5. **安全保障**：确保打包的应用及依赖无已知安全漏洞

## 常见问题

### 安装失败

- 检查 UAB 文件是否完整
- 确认系统已正确安装并启动如意玲珑运行环境
- 查看安装错误日志排查具体原因

### 运行时异常

- 检查依赖库是否完备
- 确认与当前系统环境的兼容性
- 查看应用运行日志获取详细信息

### 更新问题

- 检查网络连接是否正常
- 确认远程仓库配置无误
- 查看更新日志排查失败原因
